Requisitos do MVP TechFix

Objetivo

Desenvolver um sistema web para centralizar o gerenciamento de clientes, equipamentos e ordens de serviço da TechFix Assistência Técnica.

Requisitos funcionais

RF01: Cadastrar clientes.

RF02: Cadastrar equipamentos.

RF03: Abrir ordens de serviço.

RF04: Consultar ordens de serviço.

RF05: Atualizar o status das ordens de serviço.

RF06: Filtrar ordens de serviço por status (desejável).

Requisitos não funcionais

RNF01: Interface responsiva e de fácil utilização.

RNF02: Segurança no acesso e proteção das informações.

RNF03: Desempenho adequado nas operações do sistema.
